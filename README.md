# 1º DAW

Repositorio con los ejercicios, prácticas y documentos del primer año del ciclo formativo de **Desarrollo de Aplicaciones Web (DAW)**.

Incluye material de las asignaturas del curso: Bases de Datos, Entornos de Desarrollo, Lenguaje de Marcas, Programación, Sistemas Informáticos, IPE I, Digitalización y Sostenibilidad, además del horario del curso.

El contenido se organiza por asignatura en carpetas, y cada una recoge los trabajos y apuntes correspondientes.
